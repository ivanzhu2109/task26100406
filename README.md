# lathe — 车床 XZ 平面连续刀路碰撞验证库

仅使用 Go 标准库。验证刀尖圆盘沿轨迹段连续运动时与机床包络、卡爪之间的碰撞关系。

## 接口

```go
func CheckSegment(seg Segment, m Machine, toolRadius float64) []Interval
```

- `Segment`：`Line{Start, End}`（允许零长度）或
  `Arc{Center, Start, Sweep}`（Sweep 为有符号扫角，弧度，正逆时针，
  0 < |Sweep| ≤ 2π，支持优弧、跨零度与整圆）。
- `Machine`：`Envelope{Min, Max}`（轴对齐矩形，刀盘必须严格位于其
  内部，接触或越过边界即碰撞）与 `Jaws []Polygon`（闭合简单多边形，
  可凹、可互相重叠、无孔；内部为实体）。
- `toolRadius`：刀尖圆盘半径 r ≥ 0。坐标单位 mm，X 为半径值。
- 卡爪碰撞判据：圆盘与卡爪实体（含内部）的最短距离 ≤ r + 0.5 mm。

## 返回值

返回该段全部碰撞参数区间（u ∈ [0,1]，直线按位移、圆弧按扫角线性
插值）的并集，已合并为最大闭区间；区间间安全段保留。孤立相切表示
为 `[u, u]` 退化区间；安全零长度段返回空，碰撞零长度段返回
`[{0, 1}]`。无碰撞返回空切片。

## 数值说明

- 实现为解析法：包络与卡爪边/顶点对直线段产生二次不等式，对圆弧
  产生 `cos θ ∈ [lo, hi]` 带状不等式，直接求交/并，不做步进采样，
  因此不会漏掉窄碰撞区。
- 内部容差 `eps = 1e-9`（mm / rad / 参数 u 共用）：用于区间合并、
  边界根去重与 `≤` 比较。距离阈值比较含 1e-9 的宽松量。
- 恰好相切（间隙恰好等于阈值）的情形对输入精度敏感：间隙与阈值
  之差在 ~1e-9 mm 量级以内时，结果可能在“退化接触区间”与“无碰撞”
  之间变化；测试中的相切用例使用二进制下精确的数值（R=4, d=1,
  顶点半径 3）以避免此不确定性。
- 区间边界典型精度优于 1e-9（u），测试以 1e-6 容差断言。
